# Shukketsu

Shukketsu is a premium Discord bot built with [discord.js](https://discord.js.org/). It offers a wide range of features including server management, music playback, user interaction, and more.

## Features

- **Server Management**: Commands for managing server settings, roles, channels, and more.
- **Music Playback**: Play, pause, skip, and manage music queues with Spotify integration.
- **User Interaction**: Commands for user information, reminders, and custom messages.
- **Leveling System**: Track user activity and assign roles based on experience points.
- **Last.fm Integration**: Fetch user statistics and top artists from Last.fm.
- **Customizable Prefix**: Set a custom prefix for your server commands.
